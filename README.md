<h1>encriptado</h1>

-estado del proyecto: finalizado.

challenge de encriptado y desencriptado de texto alura latam
consiste en encriptar un texto ingresado por el usuario bajo los siguientes parametros

La letra "a" se convierte en "ai".

La letra "e" se convierte en "enter".

La letra "i" se convierte en "imes".

La letra "o" se convierte en "ober".

La letra "u" se convierte en "ufat".

y de igual manera desencripta el texto bajo los mismos parametros
